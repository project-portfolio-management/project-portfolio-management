# 致首席信息官

*首席信息官：集成、身份、数据、托管，以及您将被要求提交的信息。*

## 身份与访问

- 登录**默认强制启用**；没有令牌验证密钥，服务拒绝启动；在生产环境中关闭登录也拒绝启动。
- 通过身份提供方（包括 Microsoft Entra ID）登录；多因素认证由提供方负责（[登录指南](../../../../operations/sign-in-with-entra.md)）。
- 授权基于令牌属性（例如 `access`、`directorpack`、`confidence`）和属性策略。私有计划不出现在任何汇总中；处理标记会对高于调用者许可级别的计划隐藏，管理员也不例外。
- 访问私有计划的紧急通道需要具备资格、陈述理由、最长四小时，并通知第二个人。
- 管理员可以列出现有的访问授权（用于复核认证），并导出或假名化某个人的数据。

## 数据与集成

| 主题 | 立场 |
|---|---|
| 持有的数据 | 计划、任务、风险、预算、里程碑、工时与成本记录；人员为不透明引用，而非姓名。按设计不含患者数据和特殊类别数据 |
| 清单 | 每个个人数据列都列在[个人数据清单](../../../../governance/personal-data-inventory.csv)中；由测试保证其与数据库结构一致 |
| 接口 | REST 与推导出的 OpenAPI 文档；批量导入导出；日历订阅；仅限公共 `https` 目的地的出站事件和 webhook |
| 备份 | 脚本化备份，经过测试的恢复，可选加密，明确的恢复目标（[备份与恢复](../../../../operations/backup-and-restore.md)） |
| 托管 | 容器镜像和 `compose.yaml`；软件自身不做任何传输，所以数据所在地取决于您的托管选择 |

## 您必须弥补的差距

- 渗透测试、独立代码评审和认证：均未进行。
- 保留期只部分得到执行；必须安排清理（见[保留期计划](../../../../governance/retention-schedule.md)）。
- 数据主体工具找到的是引用，找不到键入自由文本或上传文件中的姓名。
- 审计记录无法抵御数据库管理员的篡改。
