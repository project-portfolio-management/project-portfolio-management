# 致首席安全官

*首席安全官：软件强制执行什么、项目验证了什么，以及您必须自行测试和运维的事项。*

## 软件强制执行的

| 领域 | 行为 |
|---|---|
| 认证 | 默认启用登录。没有令牌验证密钥，服务不会启动；在生产环境中关闭登录也不会启动。通过 Microsoft Entra ID 等身份提供方登录；多因素认证由提供方负责（[登录指南](../../../../operations/sign-in-with-entra.md)） |
| 授权 | 基于令牌属性的属性策略。私有计划对所有人都不计入任何汇总；处理标记会对高于调用者许可级别的计划隐藏，管理员也不例外 |
| 紧急通道 | 访问私有计划需要具备资格、陈述理由、最长四小时，并通知第二个人；每次请求都被审计 |
| 会话 | 空闲超时（默认 30 分钟）和硬性会话上限 |
| 传输与浏览器 | 安全标头、严格的内容安全策略、CORS 允许列表、按调用者的速率限制 |
| 出站 | 用户提供的目的地仅限公共 `https` 地址 |
| 上传 | 内容必须与声明的类型一致；程序被拒绝；可选的 `clamd` 扫描在失败时拒绝放行 |
| 审计 | 数据库拒绝更改和删除审计记录 |
| 冻结的记录 | 已签发的董事简报包和交付信心评估通过数据库触发器做到不可变或只追加 |
| 供应链 | `cargo deny`、软件物料清单、发布时的构建来源证明、一份[安全策略](../../../../SECURITY.md) |

## 尚未完成的

- 没有渗透测试、第三方审计、独立代码评审或认证。
- 没有内置的恶意软件扫描器；`clamd` 钩子只用替身测试过。
- 数据库管理员可以破坏审计记录；没有哈希链。
- 处理标记只隐藏和标注，不加密，标记也不会写入生成的文件。
- 除非配置 Redis，会话保存在内存中。
- 数据主体工具找到的是引用，找不到键入自由文本、上传文件或备份中的姓名。

## 运维

备份具有经过测试的恢复、可选加密和明确的恢复目标（[运维包](../../../../operations/README.md)）。[运行手册](../../../../operations/runbook.md)给出技术性的事件处理步骤；事件和泄露处理流程由您负责。请按 [SECURITY.md](../../../../SECURITY.md) 的说明私下报告漏洞；目标是 5 个工作日内确认，不是保证。

## 属于您的决定

由谁、何时进行渗透测试；身份提供方的条件访问和角色映射；本部署获得保证的标记级别；附件钩子背后的扫描器；访问复核的频率。
