# 优势

*您的组织会发生哪些变化，以及哪些仍由您决定。*

## 看清整个组合

大多数组织把组合信息同时放在好几个地方。在这里，每个组合、项目集、项目和产品都是同一种记录，称为**计划**。任何计划都可以包含任何其他计划，层级不限，因此结构可以贴合您的实际工作方式。“项目”这样的标签只是描述计划，不构成任何限制。

## 不再为同一件事出资两次

两个部门可能以不同名称为同一举措立项。匹配器比较能够识别计划的信息：名称、目标、负责人、发起人、上级计划、时间范围、关键词和标识符。它适用于所有类型的计划，并展示每次匹配的证据，由人来做决定。当两条记录是同一计划时，您可以将它们合并。

## 信任您看到的内容

- 缺失的数字会说明缺失的原因：“无预测，因为……”。
- 无人评估的计划显示“未评估”，绝不显示绿色。
- 由人给出的交付信心显示在计算状态旁边，绝不与之混合。
- 私有计划不计入任何总计和计数，对所有人都如此，这条规则由测试检查。
- 每个工期都注明是日历日还是工作日。

## 说明决定是如何做出的

每项变更都有审计记录，审计记录无法通过服务更改。提出变更请求的人不能批准自己的请求。每月董事报告包只起草一次，由具名人员发布，然后由数据库冻结：更正是一个带说明的新版本。

## 从安全开始

默认启用登录，如果关闭登录，服务会拒绝在生产环境中启动。安全标头、速率限制、带有明确目标的恢复计划以及信息治理资料包都是仓库的一部分，而不是额外的东西。

## 保持掌控

- **免费且开源。** 可在 MIT、Apache-2.0、BSD-3-Clause、GPL-2.0 和 GPL-3.0 中任选。
- **自行运行。** 一个基于 PostgreSQL 的 Rust 服务，配有 SvelteKit 界面。
- **带上您的工作。** 从 Jira 和 Asana 导入 CSV，提供预览，并说明未导入内容的原因。可导入和导出 Microsoft Project XML。
- **使用您的语言。** 界面提供十种语言区域，包括从右到左的阿拉伯语。译文均为草稿，等待母语人士审阅。
