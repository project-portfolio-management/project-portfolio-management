# Для директора по информационным технологиям

*Директор по информационным технологиям: интеграция, удостоверения, данные, размещение и сведения, которые у вас запросят.*

## Удостоверения и доступ

- Вход **обязателен по умолчанию**; сервис отказывается запускаться без ключей проверки токенов, а в производственной среде — с отключённым входом.
- Вход через поставщика удостоверений (включая Microsoft Entra ID); многофакторная аутентификация остаётся за поставщиком ([руководство по входу](../../../../operations/sign-in-with-entra.md)).
- Авторизация использует атрибуты токена (например, `access`, `directorpack`, `confidence`) с политикой атрибутов. Закрытые планы скрыты из всех сводных показателей; грифы обращения скрывают планы выше допуска вызывающего, включая администраторов.
- Аварийный доступ к закрытым планам требует права на него, указанной причины, не более четырёх часов и уведомления второго лица.
- Администраторы могут просмотреть список действующих прав доступа (помощь при повторной сертификации) и экспортировать или псевдонимизировать данные одного человека.

## Данные и интеграция

| Тема | Положение |
|---|---|
| Хранимые данные | Записи о планах, задачах, рисках, бюджетах, вехах, времени и стоимости; люди представлены непрозрачными ссылками, а не именами. По замыслу нет данных о пациентах и данных особых категорий |
| Перечень | Каждый столбец с персональными данными указан в [перечне персональных данных](../../../../governance/personal-data-inventory.csv); тест следит за его соответствием схеме |
| Интерфейсы | REST с производным документом OpenAPI; массовый импорт и экспорт; календарные ленты; исходящие события и вебхуки только на публичные адреса `https` |
| Резервные копии | Резервное копирование по сценарию с проверенным восстановлением, необязательное шифрование, заявленные целевые показатели восстановления ([резервное копирование и восстановление](../../../../operations/backup-and-restore.md)) |
| Размещение | Образы контейнеров и `compose.yaml`; программа сама ничего не передаёт, поэтому местоположение данных определяется вашим выбором хостинга |

## Пробелы, которые вы должны закрыть

- Тестирование на проникновение, независимая проверка кода и сертификация: ничего не сделано.
- Хранение соблюдается лишь частично; очистку нужно поставить в расписание (см. [график хранения](../../../../governance/retention-schedule.md)).
- Инструмент для запросов субъектов данных находит ссылки, но не имена, введённые в свободный текст или загруженные файлы.
- Журнал аудита не защищён от подделки администратором базы данных.
