# 功能

*按領域列出的功能摘要。登記冊和專案工作區共用同一條記錄。*

## 計劃與匹配

- 一個可遞迴的計劃集合，可選用組合、專案集或專案等標籤
- 跨所有型別計劃的可解釋重複匹配
- 將同一計劃的兩條記錄合併為一條

## 日常工作

- 個人「我的工作」頁面和個人看板
- 任務板、日曆和里程碑
- 已儲存檢視，以及跨組合搜尋

## 進度安排

- 甘特圖和工作分解結構
- 關鍵路徑，支援 Microsoft Project 的八種約束型別
- 基線、進度健康度和資源平衡
- 關鍵鏈，包括緩衝、緩衝管理和鼓

## 資金

- 預算行、成本和資金臺賬
- 掙值
- 成本風險，以及成本與進度的綜合風險

## 人員與產能

- 資源、角色、技能池和可用性
- 產能熱力圖和產能承諾
- 關鍵人員

## 戰略與工作受理

- 工作受理，包括提案和創意
- 目標、目標與關鍵成果，以及關鍵指標
- 用於假設規劃的情景，以及限制在製品的啟動佇列

## 治理與升級

- 風險登記冊和問題
- 階段門評審、里程碑籤核和切換決策
- 帶計時的例外事項，以及升級路徑
- 每月董事報告包
- 由組織定義的問題型別和狀態，狀態轉換可按問題型別區分，並可按角色限制

## 安全與運維

- 預設登入，可透過外部身份提供方登入，包括透過 Keycloak 使用 Microsoft Entra ID
- 無法透過服務更改的審計記錄
- 速率限制和安全標頭
- 備份和恢復工具，以及經過測試的恢復演練

## 尚不可用

當前版本不包括：

- 移動應用或桌面應用
- 實時協同編輯
- 用於起草或裁決變更請求的介面（變更請求目前只能透過服務使用）
- 董事報告包的 PDF 或介面（目前以資料形式提供），以及若干計劃中的章節

[專案待辦清單](https://github.com/project-portfolio-management/project-portfolio-management/blob/main/tasks.md)記錄了每一項的侷限。
