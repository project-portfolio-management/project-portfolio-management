# Project Portfolio Management and Smartsheet

*A smarter spreadsheet, or a purpose-built registry?*

**How this page was written.** Nobody installed or ran Smartsheet for this comparison. Its description is general, and it may be out of date, so please check Smartsheet's own documentation. Different products solve different problems, so nothing here is scored. The facts about this project come from its own repository.

## What Smartsheet is

A hosted work management tool with a spreadsheet-like way of working.

## Smartsheet may suit you better if

- Your people think in rows and columns and want to stay there
- You want a hosted service with vendor support
- You want flexible sheets more than a fixed vocabulary

## This project may suit you better if

- You want every plan to be one kind of record, with any plan inside any other
- You need to find duplicates, not just list them
- You need access rules that keep private plans out of every total and count
- You want to run it on your own servers

## Moving your work

There is **no Smartsheet importer**. You can paste tab-separated rows of tasks into a task board.

## Before you decide

This project is young, with one maintainer and no third-party audit. Its own verdict is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing. Read [where it is behind](../../topics/comparisons/index.md#where-it-is-behind).
