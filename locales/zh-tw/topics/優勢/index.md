# 優勢

*按領域列出軟體為組織帶來的主要優勢。*

## 組合可見性

組合資訊通常分散在多個地方。在本軟體中，每個組合、專案集、專案和產品都是同一種記錄型別，稱為**計劃**。任何計劃都可以包含任何其他計劃，層級不限，因此結構可以與組織相匹配。「專案」等標籤僅作描述，不對計劃構成限制。

## 減少重複

兩個部門可能以不同名稱為同一舉措立項。匹配器比較用於識別計劃的屬性：名稱、目標、負責人、發起人、上級計劃、時間範圍、關鍵詞和識別符號。它適用於所有型別的計劃，並展示每次匹配的證據，由人員作出決定。同一計劃的兩條記錄可以合併。

## 報告質量

- 缺失的數字附帶原因，例如「無預測，因為……」。
- 未經評估的計劃顯示為「未評估」。
- 人員記錄的交付信心顯示在計算狀態旁邊，兩者分開儲存。
- 私有計劃不計入所有使用者的任何總計和計數。這條規則由測試檢查。
- 每個工期都註明單位是日曆日還是工作日。

## 決策記錄

每項變更都有審計記錄，審計記錄無法透過服務更改。提出變更請求的人不能批准該請求。每月董事報告包起草一次，由具名人員釋出，然後由資料庫凍結。更正以帶說明的新版本釋出。

## 安全

預設啟用登入，關閉登入時服務不會在生產環境中啟動。倉庫包含安全標頭、速率限制、帶有明確目標的恢復計劃以及資訊治理資料包。

## 控制與可移植性

- **許可。** 軟體為開源軟體，可在 MIT、Apache-2.0、BSD-3-Clause、GPL-2.0、GPL-3.0、OGL-UK-3.0 或 CC-BY-NC-SA-4.0 中選擇。
- **託管。** 軟體由組織自行託管：一個基於 PostgreSQL 的 Rust 服務，配有 SvelteKit 介面。
- **資料匯入。** 可匯入 Jira 和 Asana 的 CSV 檔案，提供預覽並說明排除內容的原因。可匯入和匯出 Microsoft Project XML。
- **語言。** 介面提供十種語言區域，包括從右到左的阿拉伯語。譯文均為草稿，等待母語人士審閱。
