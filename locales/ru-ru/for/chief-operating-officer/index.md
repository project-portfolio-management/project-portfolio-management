# Для операционного директора

*Операционный директор: чем вы руководите изо дня в день, что программа делает для выполнения работ и что требуется для её эксплуатации.*

## Что она делает для операционной деятельности

- **Планирование и контроль выполнения:** планы, задачи, зависимости, расчёт критического пути, вехи по планам, спринты и фазы, диаграмма сгорания и показатели потока.
- **Ёмкость:** распределения, доступность, отпуска и нерабочие периоды, ресурсные роли, производные нагрузка и использование. (Тепловая карта загрузки по пулам навыков и месяцам для пакета директора не создана: `DP-10`.)
- **Время и стоимость:** табели, учтённое время, ставки стоимости (с ограниченным доступом для финансов), бюджеты и производная стоимость.
- **Поток управления:** реестр проблем, запросы на изменение с разделением обязанностей (автор не может утвердить), утверждения, проверки, случаи приёма, перевода и увольнения сотрудников.
- **Исключения:** красная или жёлто-красная уверенность в выполнении открывает исключение, для которого нужны причина, необходимое решение, назначенный владелец и срок принятия решения в пределах 48 часов (окно настраивается, от 1 до 720 часов). Нарушения отображаются в пакете директора и в `GET /api/exceptions`.

## Что требуется для эксплуатации

| Потребность | Подробности |
|---|---|
| Сервис | Один сервис на Rust, PostgreSQL 18, необязательный Redis (кэш в промышленной среде, необязательные общие сеансы), интерфейс на SvelteKit |
| Руководство по эксплуатации | [пакет эксплуатации](../../../../operations/README.md): развёртывание, руководство по эксплуатации, резервное копирование и восстановление, целевые показатели восстановления, обновление и миграция |
| Плановые задания | Ничто не запускается само. Очистку по сроку хранения, уведомления о нарушении исключений и подобные задачи ваши операторы должны поставить в планировщик |
| Поддержка | Один сопровождающий, нет SLA; закладывайте бюджет на собственную первую линию поддержки |

## Знайте ограничения

- План из нескольких тысяч задач планируется медленно; полный ответ отклоняется для планов свыше 5000 задач, если он не запрошен явно (`?full=true` или `?only=critical`). Цифры и оговорки приведены в [`BENCHMARKS.md`](../../../../BENCHMARKS.md); это порядок величины на одной машине, а не ёмкость.
- Экраны существуют для большей части рабочего пространства, но **пока не** для запросов на изменение, проблем, пакетов и уверенности в выполнении; сегодня они доступны только через API.
