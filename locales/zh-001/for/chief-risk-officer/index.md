# 致首席风险官

*首席风险官：软件帮助您看到的风险，以及使用它的风险。*

## 它帮助您管理的风险

- **风险、问题和变更请求**按计划记录；跨可读计划的问题登记册；带职责分离的变更请求。
- **交付信心与例外：** 陈述的信心与计算所得的 RAG 分开，二者相差两级时标出，历史只追加；48 小时例外计时在评级恶化时不会重新开始，只有记录在案的决定才能关闭。
- **如实表示缺失：** 缺失的数据显示为“未评估”或附理由的空值，绝不显示为绿色或零。
- **冻结、有版本的月度简报包，**因此可以日后按签发时的原样出示曾告知董事的内容。

## 使用它的风险（项目自己的登记册）

| 风险 | 状态 |
|---|---|
| 没有渗透测试、第三方审计或认证 | 未决：由买方委托（[保证清单](../../../../governance/assurance-checklist.md)） |
| 只对部分数据执行保留期 | 未决；必须安排清理 |
| 数据主体工具不搜索自由文本、附件或备份 | 未决 |
| 审计记录可被数据库管理员破坏；没有哈希链 | 已在 [DPIA](../../../../governance/dpia.md) 中说明 |
| 处理标记只隐藏和标注，不加密 | 已说明 |
| 附件扫描需要部署方运行扫描器 | 未决 |
| 单一维护者，无服务水平协议 | 未决 |
| 译文为草稿 | 未决 |
| 仅限非临床；没有临床安全案例 | 请勿输入临床内容 |

## 软件强制执行的控制

默认登录、速率限制、严格的安全标头、空闲会话超时（30 分钟）和硬性会话上限、仅限公共 `https` 的出站目的地、校验签名的附件、不可变的审计行、带审计的紧急通道。每一项都有测试覆盖，见[生产就绪度](../../../../governance/production-readiness.md)。

## 属于您的决定

试点的风险偏好；例外窗口（默认 48 小时）；本部署获得保证的标记级别；谁复核访问清单以及多久一次。
