# Project Portfolio Management and Planview

*An enterprise suite, or an open-source pilot?*

**How this page was written.** Nobody installed or ran Planview for this comparison. Its description is general, and it may be out of date, so please check Planview's own documentation. Different products solve different problems, so nothing here is scored. The facts about this project come from its own repository.

## What Planview is

A commercial suite for enterprise portfolio and work management.

## Planview may suit you better if

- You need an established enterprise vendor, with support and a long production history
- You need a third-party audit and certifications, which this project does not have
- You need to go into unsupervised production now

## This project may suit you better if

- You want open-source software, with five licences to choose from
- You want to read how it works, down to the code and the tests
- You want to start with a controlled pilot on your own servers
- You value a backlog that says what each item does not do

## Moving your work

There is **no Planview importer**. Plans can be created through the REST API.

## Before you decide

This project is young, with one maintainer and no third-party audit. Its own verdict is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing. Read [where it is behind](../../topics/comparisons/index.md#where-it-is-behind).

Spotted a mistake? Please [open an issue](https://github.com/project-portfolio-management/project-portfolio-management/issues) with a source.
