# 最高セキュリティ責任者（CSO）向け

*最高セキュリティ責任者: ソフトウェアが強制すること、プロジェクトが検証したこと、そしてあなた自身がテストし運用しなければならないこと。*

## ソフトウェアが強制すること

| 領域 | 動作 |
|---|---|
| 認証 | ログインは初期状態で有効です。トークン検証キーがなければサービスは起動せず、本番でログインが無効の場合も起動しません。Microsoft Entra ID などのアイデンティティプロバイダーによるサインイン。多要素認証はプロバイダー側で行います（[サインインガイド](../../../../operations/sign-in-with-entra.md)） |
| 認可 | トークンの属性に基づく属性ベースのポリシー。非公開の計画は、誰にとってもすべての集計から除外されます。取り扱い区分により、呼び出し元のクリアランスを超える計画は管理者に対しても隠されます |
| ブレークグラス | 非公開の計画へのアクセスには、資格、理由の記載、最大四時間の制限、第二の人への通知が必要です。すべての要求は監査されます |
| セッション | アイドルタイムアウト（既定 30 分）と絶対的なセッション上限 |
| 通信とブラウザー | セキュリティヘッダー、厳格な Content Security Policy、CORS の許可リスト、呼び出し元ごとのレート制限 |
| 送信 | ユーザーが指定する送信先は、公開 `https` アドレスに限定されます |
| アップロード | 内容は宣言された種類と一致する必要があります。プログラムは拒否され、任意の `clamd` スキャンは失敗時に閉じる動作です |
| 監査 | 監査証跡は、データベースで変更と削除を拒否します |
| 凍結された記録 | 発行済みのディレクターパックと実行の確信度の評価は、データベーストリガーにより不変または追記専用です |
| サプライチェーン | `cargo deny`、ソフトウェア部品表、リリース時のビルド来歴、[セキュリティポリシー](../../../../SECURITY.md) |

## 未実施のこと

- ペネトレーションテスト、第三者監査、独立したコードレビュー、認証はありません。
- マルウェアスキャナーは同梱されていません。`clamd` のフックは代用品に対してのみテストされています。
- 監査証跡は、データベース管理者に破られうるもので、ハッシュチェーンはありません。
- 取り扱い区分は隠してラベルを付けるだけで暗号化はせず、区分は生成ファイルに刻印されません。
- Redis を設定しない限り、セッションはメモリに保持されます。
- データ主体ツールが見つけるのは参照であり、自由記述、アップロードされたファイル、バックアップに入力された氏名ではありません。

## 運用

バックアップには、検証済みの復元、任意の暗号化、明記した復旧目標があります（[運用パック](../../../../operations/README.md)）。[ランブック](../../../../operations/runbook.md)は技術的なインシデント対応の手順を示しますが、インシデントと情報漏えいのプロセスはあなたのものです。脆弱性は、[SECURITY.md](../../../../SECURITY.md) の説明に従って非公開で報告してください。目標は営業日 5 日以内の受領確認であり、保証ではありません。

## あなたが決めること

誰がいつペネトレーションテストを行うか、アイデンティティプロバイダーの条件付きアクセスとロールのマッピング、この導入が保証を受ける区分レベル、添付ファイルのフックの背後にあるスキャナー、アクセスを再認証する頻度。
