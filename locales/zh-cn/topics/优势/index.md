# 优势

*按领域列出软件为组织带来的主要优势。*

## 组合可见性

组合信息通常分散在多个地方。在本软件中，每个组合、项目集、项目和产品都是同一种记录类型，称为**计划**。任何计划都可以包含任何其他计划，层级不限，因此结构可以与组织相匹配。“项目”等标签仅作描述，不对计划构成限制。

## 减少重复

两个部门可能以不同名称为同一举措立项。匹配器比较用于识别计划的属性：名称、目标、负责人、发起人、上级计划、时间范围、关键词和标识符。它适用于所有类型的计划，并展示每次匹配的证据，由人员作出决定。同一计划的两条记录可以合并。

## 报告质量

- 缺失的数字附带原因，例如“无预测，因为……”。
- 未经评估的计划显示为“未评估”。
- 人员记录的交付信心显示在计算状态旁边，两者分开保存。
- 私有计划不计入所有用户的任何总计和计数。这条规则由测试检查。
- 每个工期都注明单位是日历日还是工作日。

## 决策记录

每项变更都有审计记录，审计记录无法通过服务更改。提出变更请求的人不能批准该请求。每月董事报告包起草一次，由具名人员发布，然后由数据库冻结。更正以带说明的新版本发布。

## 安全

默认启用登录，关闭登录时服务不会在生产环境中启动。仓库包含安全标头、速率限制、带有明确目标的恢复计划以及信息治理资料包。

## 控制与可移植性

- **许可。** 软件为开源软件，可在 MIT、Apache-2.0、BSD-3-Clause、GPL-2.0 或 GPL-3.0 中选择。
- **托管。** 软件由组织自行托管：一个基于 PostgreSQL 的 Rust 服务，配有 SvelteKit 界面。
- **数据导入。** 可导入 Jira 和 Asana 的 CSV 文件，提供预览并说明排除内容的原因。可导入和导出 Microsoft Project XML。
- **语言。** 界面提供十种语言区域，包括从右到左的阿拉伯语。译文均为草稿，等待母语人士审阅。
