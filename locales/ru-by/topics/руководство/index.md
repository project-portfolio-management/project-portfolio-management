# Руководство

*Шаги по запуску демонстрации на локальном компьютере и просмотру образца портфеля.*

Демонстрация — это полная копия программы, загруженная данными вымышленной организации, Северного транспортного управления (Northgate Transport Authority). Все люди, планы, цифры и даты вымышлены, а данные можно свободно менять.

**Примечание по безопасности.** Демонстрация доверяет опубликованному тестовому ключу. Её нельзя запускать в общей сети или использовать с реальными данными.

## Требования

- [Git](https://git-scm.com/)
- [Podman](https://podman.io/) с Compose

## Шаг 1: загрузите код

```sh
git clone https://github.com/project-portfolio-management/project-portfolio-management.git
cd project-portfolio-management
```

## Шаг 2: запустите демонстрацию

```sh
POSTGRES_PASSWORD=demo podman compose --profile demo up -d --build --wait ui-demo
```

Эта команда собирает программу, запускает базу данных, загружает вымышленный портфель и запускает интерфейс. Первая сборка занимает больше времени, чем последующие.

## Шаг 3: войдите

Откройте <http://localhost:3000/ru-by/signin>, оставьте адрес `example@example.com` и нажмите **Sign in to the demonstration**. Письмо не отправляется.

Первая страница — **демонстрационный тур**, где перечислены все возможности по группам, с описанием и ссылкой. Жёлтый баннер на каждой странице сообщает, что данные вымышлены.

## Шаг 4: просмотрите портфель

В туре откройте **Plans**, чтобы увидеть портфель, его программы и проекты. Затем откройте **Portfolio dashboard**.

## Шаг 5: просмотрите один проект

Откройте проект **North Line interlocking** через группу тура, посвящённую выполнению. Просмотрите его диаграмму **Gantt**, **Critical path** и **Earned value**.

## Шаг 6: просмотрите личную работу

Откройте **My work** и **My kanban board**. Сеанс выполнен от имени Example Person, у которого есть открытые задачи.

## Шаг 7: просмотрите ёмкость, контроль запуска и отчётность

Откройте **Capacity heatmap**, чтобы увидеть перегруженные ресурсы. Откройте **Start queue**, где ограничение незавершённой работы задержало одну программу. Откройте **Director packs** — ежемесячную сводку, которая замораживается после выпуска.

## Шаг 8: остановите демонстрацию

Эта команда останавливает все сервисы и удаляет данные демонстрации:

```sh
podman compose --profile demo down -v
```
