# 项目组合管理

*已出资工作的登记册，附带重复检测和项目管理工作区。*

项目组合管理是一款开源软件，用于记录组织出资的计划并管理其中的工作，涵盖任务、进度、成本、资源、风险和治理。软件比较各项计划以识别可能的重复，并展示每次匹配的证据。无法计算某一数字时，软件会说明原因。

## 主要优势

- **统一的组合记录。** 组合、项目集、项目和产品使用同一种记录类型，任何计划都可以包含其他计划。各部门的报告都基于同一份清单。
- **重复检测。** 匹配功能比较以不同名称记录的计划，并展示每项结果的证据，以便审核人员在两者都获得资金之前采取行动。
- **可追溯的数字。** 缺失的数字会附带缺失原因。未经评估的计划显示为“未评估”。
- **审计记录。** 每项变更都有审计记录。提出变更请求的人不能批准该请求。
- **访问控制。** 默认启用登录，关闭登录时服务不会在生产环境中运行。
- **部署与许可。** 软件由组织自行托管，提供五种开源许可证。可从 Jira、Asana 和 Microsoft Project 导入工作。

## 功能领域

- **计划与匹配。** 可递归的登记册、可解释的重复检测和合并。
- **交付。** 看板、甘特图、日历、里程碑、关键路径和关键链。
- **财务。** 预算、资金台账、挣值，以及成本和进度风险。
- **资源。** 技能池、产能热力图和关键人员。
- **战略。** 工作受理、创意、目标、目标与关键成果，以及情景。
- **治理。** 风险、问题、阶段门评审、升级和每月董事报告包。

## 目标用户

- **组合管理办公室。** 跨项目集和项目的报告。
- **项目和交付经理。** 进度、成本和风险管理。
- **团队成员。** 个人工作视图。
- **高级管理人员。** [角色简报](for/)说明软件为各角色提供的内容、其局限以及所需的决定。

## 当前状态

该软件处于早期阶段，只有一位维护者，没有第三方审计，也没有支持协议。项目自身的评估是：**已可用于受控试点**（非临床、非机密数据），**尚不能用于无人监督的生产环境**。已知局限列于[比较页面](topics/比较/index.md)。
