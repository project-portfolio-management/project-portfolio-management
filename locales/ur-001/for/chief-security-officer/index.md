# چیف سیکیورٹی آفیسر کے لیے

*چیف سیکیورٹی آفیسر: سافٹ ویئر کیا نافذ کرتا ہے، پراجیکٹ نے کیا جانچا ہے، اور آپ کو خود کیا جانچنا اور چلانا ہے۔*

## سافٹ ویئر کیا نافذ کرتا ہے

| شعبہ | رویہ |
|---|---|
| تصدیق | لاگ اِن بطورِ طے شدہ فعال ہے۔ سروس ٹوکن کی تصدیق کی کلیدوں کے بغیر شروع نہیں ہوگی، اور پروڈکشن میں لاگ اِن بند ہونے پر شروع نہیں ہوگی۔ Microsoft Entra ID جیسے شناختی فراہم کنندہ کے ذریعے سائن اِن؛ ملٹی فیکٹر تصدیق فراہم کنندہ کے پاس رہتی ہے ([سائن اِن کی رہنمائی](../../../../operations/sign-in-with-entra.md)) |
| اجازت | ٹوکن کی صفات پر صفاتی پالیسی۔ نجی پلان سب کے لیے ہر مجموعے سے باہر رکھے جاتے ہیں؛ ہینڈلنگ کے نشانات کال کرنے والے کی اجازت سے اوپر کے پلان چھپا دیتے ہیں، منتظمین سمیت |
| ہنگامی رسائی (break-glass) | نجی پلانوں تک رسائی کے لیے اہلیت، بتائی گئی وجہ، زیادہ سے زیادہ چار گھنٹے اور دوسرے شخص کو اطلاع درکار ہے؛ ہر درخواست کا آڈٹ ہوتا ہے |
| سیشن | غیر فعالی کا ٹائم آؤٹ (بطورِ طے شدہ 30 منٹ) اور سیشن کی سخت حد |
| ٹرانسپورٹ اور براؤزر | سلامتی کے ہیڈر، سخت Content Security Policy، CORS کی اجازت یافتہ فہرست، فی صارف شرحِ درخواست کی حد |
| باہر جانے والا | صارف کی دی ہوئی منزلیں عوامی `https` پتوں تک محدود ہیں |
| اپ لوڈ | مواد اعلان کردہ قسم سے ملنا چاہیے؛ پروگرام مسترد کیے جاتے ہیں؛ اختیاری `clamd` اسکین ناکامی پر بند ہو جاتا ہے |
| آڈٹ | آڈٹ ٹریل ڈیٹا بیس میں تبدیلی اور حذف کو مسترد کرتی ہے |
| منجمد ریکارڈ | جاری شدہ ڈائریکٹر پیک اور تکمیل کے اعتماد کے جائزے ڈیٹا بیس ٹرگر کے ذریعے ناقابلِ تبدیل یا صرف اضافہ والے ہیں |
| سپلائی چین | `cargo deny`، سافٹ ویئر بل آف میٹیریلز، ریلیز پر بلڈ کی اصلیت، [سلامتی کی پالیسی](../../../../SECURITY.md) |

## جو نہیں کیا گیا

- کوئی پینیٹریشن ٹیسٹ، تیسرے فریق کا آڈٹ، آزاد کوڈ جائزہ یا تصدیق نہیں۔
- کوئی میل ویئر اسکینر شامل نہیں؛ `clamd` ہُک صرف ایک متبادل کے ساتھ آزمایا گیا۔
- ڈیٹا بیس ایڈمنسٹریٹر آڈٹ ٹریل کو ناکام کر سکتا ہے؛ کوئی ہیش چین نہیں۔
- ہینڈلنگ کے نشانات چھپاتے اور لیبل لگاتے ہیں؛ خفیہ نہیں کرتے، اور نشان بنائی گئی فائلوں میں ثبت نہیں ہوتا۔
- سیشن میموری میں رکھے جاتے ہیں جب تک Redis ترتیب نہ دیا جائے۔
- ڈیٹا کے مالک کا آلہ حوالے ڈھونڈتا ہے، آزاد متن، اپ لوڈ کی گئی فائلوں یا بیک اپ میں ٹائپ کیے گئے نام نہیں۔

## اسے چلانا

بیک اپ کی بحالی آزمودہ ہے، خفیہ کاری اختیاری ہے اور بحالی کے اہداف بتائے گئے ہیں ([آپریشنز پیک](../../../../operations/README.md))۔ [رن بک](../../../../operations/runbook.md) واقعات کے تکنیکی مراحل دیتی ہے؛ واقعے اور ڈیٹا کی خلاف ورزی کا طریقہ کار آپ کا ہے۔ کمزوری کی اطلاع نجی طور پر دیں، جیسا کہ [SECURITY.md](../../../../SECURITY.md) بیان کرتا ہے؛ ہدف 5 کاروباری دنوں میں تصدیقِ وصولی ہے، ضمانت نہیں۔

## جو فیصلے آپ کے ہیں

پینیٹریشن ٹیسٹ کون کرتا ہے اور کب؛ شناختی فراہم کنندہ کی مشروط رسائی اور کرداروں کی نقشہ بندی؛ اس تنصیب کے لیے نشان کی کس سطح کی یقین دہانی ہے؛ منسلکات کے ہُک کے پیچھے اسکینر؛ رسائی کی دوبارہ توثیق کتنی بار ہوتی ہے۔
