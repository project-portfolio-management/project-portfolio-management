# Project Portfolio Management and Asana

*Team work management compared with portfolio governance.*

**Basis of this comparison.** Asana was not installed or run for this comparison. The description is general and may be out of date, and Asana's current documentation should be checked before a decision is made. Products are not scored. Statements about this project are taken from its repository.

## About Asana

A hosted work management tool for tasks, projects and team coordination, used across many functions.

## When Asana may be the better fit

- The main need is a hosted tool for everyday team coordination
- Native mobile apps and real-time collaboration are required; this project has neither
- Vendor support is required

## When this project may be the better fit

- Critical path, earned value and critical chain are required
- Governance is required, including gate reviews, exceptions with a time limit, and director packs that are frozen once issued
- Explainable duplicate matching is required
- Self-hosting is required

## Migration

An **Asana CSV export** can be imported, with a preview and a stated reason for anything excluded. Plans can record an Asana GID. A shared identifier counts as a definite match, so two plans with the same identifier are treated as the same plan.

## Project status

This project is at an early stage, with one maintainer and no third-party audit. Its own assessment is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing. See [known limitations](../../topics/comparisons/index.md#known-limitations).
