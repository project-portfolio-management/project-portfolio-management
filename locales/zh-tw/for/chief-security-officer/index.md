# 致首席安全官

*首席安全官：軟體強制執行什麼、專案驗證了什麼，以及您必須自行測試和運維的事項。*

## 軟體強制執行的

| 領域 | 行為 |
|---|---|
| 認證 | 預設啟用登入。沒有令牌驗證金鑰，服務不會啟動；在生產環境中關閉登入也不會啟動。透過 Microsoft Entra ID 等身份提供方登入；多因素認證由提供方負責（[登入指南](../../../../operations/sign-in-with-entra.md)） |
| 授權 | 基於令牌屬性的屬性策略。私有計劃對所有人都不計入任何彙總；處理標記會對高於呼叫者許可級別的計劃隱藏，管理員也不例外 |
| 緊急通道 | 訪問私有計劃需要具備資格、陳述理由、最長四小時，並通知第二個人；每次請求都被審計 |
| 會話 | 空閒超時（預設 30 分鐘）和硬性會話上限 |
| 傳輸與瀏覽器 | 安全標頭、嚴格的內容安全策略、CORS 允許列表、按呼叫者的速率限制 |
| 出站 | 使用者提供的目的地僅限公共 `https` 地址 |
| 上傳 | 內容必須與宣告的型別一致；程式被拒絕；可選的 `clamd` 掃描在失敗時拒絕放行 |
| 審計 | 資料庫拒絕更改和刪除審計記錄 |
| 凍結的記錄 | 已簽發的董事簡報包和交付信心評估透過資料庫觸發器做到不可變或只追加 |
| 供應鏈 | `cargo deny`、軟體物料清單、釋出時的構建來源證明、一份[安全策略](../../../../SECURITY.md) |

## 尚未完成的

- 沒有滲透測試、第三方審計、獨立程式碼評審或認證。
- 沒有內建的惡意軟體掃描器；`clamd` 鉤子只用替身測試過。
- 資料庫管理員可以破壞審計記錄；沒有雜湊鏈。
- 處理標記只隱藏和標註，不加密，標記也不會寫入生成的檔案。
- 除非配置 Redis，會話儲存在記憶體中。
- 資料主體工具找到的是引用，找不到鍵入自由文字、上傳檔案或備份中的姓名。

## 運維

備份具有經過測試的恢復、可選加密和明確的恢復目標（[運維包](../../../../operations/README.md)）。[執行手冊](../../../../operations/runbook.md)給出技術性的事件處理步驟；事件和洩露處理流程由您負責。請按 [SECURITY.md](../../../../SECURITY.md) 的說明私下報告漏洞；目標是 5 個工作日內確認，不是保證。

## 屬於您的決定

由誰、何時進行滲透測試；身份提供方的條件訪問和角色對映；本部署獲得保證的標記級別；附件鉤子背後的掃描器；訪問複核的頻率。
