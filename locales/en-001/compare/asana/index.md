# Project Portfolio Management and Asana

*Team work management, or portfolio governance?*

**How this page was written.** Nobody installed or ran Asana for this comparison. Its description is general, and it may be out of date, so please check Asana's own documentation. Different products solve different problems, so nothing here is scored. The facts about this project come from its own repository.

## What Asana is

A hosted work management tool for tasks, projects and team coordination, used well beyond software teams.

## Asana may suit you better if

- You want a polished hosted tool for everyday team coordination
- You need native mobile apps and real-time collaboration, which this project does not have
- You need vendor support

## This project may suit you better if

- You need critical path, earned value and critical chain
- You need governance: gate reviews, exceptions with a clock, and director packs that are frozen once issued
- You need explainable duplicate matching
- You want to run it on your own servers

## Moving your work

Import an **Asana CSV export**, with a preview and a stated reason for everything left out. Plans can record an Asana GID, and a shared identifier counts as a sure match, so two plans pointing at the same one are found as the same plan.

## Before you decide

This project is young, with one maintainer and no third-party audit. Its own verdict is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing. Read [where it is behind](../../topics/comparisons/index.md#where-it-is-behind).
