# 專案組合管理

*已出資工作的登記冊，附帶重複檢測和專案管理工作區。*

專案組合管理是一款開源軟體，用於記錄組織出資的計劃並管理其中的工作，涵蓋任務、進度、成本、資源、風險和治理。軟體比較各項計劃以識別可能的重複，並展示每次匹配的證據。無法計算某一數字時，軟體會說明原因。

## 主要優勢

- **統一的組合記錄。** 組合、專案集、專案和產品使用同一種記錄型別，任何計劃都可以包含其他計劃。各部門的報告都基於同一份清單。
- **重複檢測。** 匹配功能比較以不同名稱記錄的計劃，並展示每項結果的證據，以便稽核人員在兩者都獲得資金之前採取行動。
- **可追溯的數字。** 缺失的數字會附帶缺失原因。未經評估的計劃顯示為「未評估」。
- **審計記錄。** 每項變更都有審計記錄。提出變更請求的人不能批准該請求。
- **訪問控制。** 預設啟用登入，關閉登入時服務不會在生產環境中執行。
- **部署與許可。** 軟體由組織自行託管，提供五種開源許可證。可從 Jira、Asana 和 Microsoft Project 匯入工作。

## 功能領域

- **計劃與匹配。** 可遞迴的登記冊、可解釋的重複檢測和合並。
- **交付。** 看板、甘特圖、日曆、里程碑、關鍵路徑和關鍵鏈。
- **財務。** 預算、資金臺賬、掙值，以及成本和進度風險。
- **資源。** 技能池、產能熱力圖和關鍵人員。
- **戰略。** 工作受理、創意、目標、目標與關鍵成果，以及情景。
- **治理。** 風險、問題、階段門評審、升級和每月董事報告包。

[檢視全部功能](topics/功能/index.md)

## 目標使用者

- **組合管理辦公室。** 跨專案集和專案的報告。
- **專案和交付經理。** 進度、成本和風險管理。
- **團隊成員。** 個人工作檢視。
- **高階管理人員。** [角色簡報](for/)說明軟體為各角色提供的內容、其侷限以及所需的決定。

## 當前狀態

該軟體處於早期階段，只有一位維護者，沒有第三方審計，也沒有支援協議。投入生產使用需要什麼，逐項及每項的估計，見[通往生產之路](path-to-production/index.md)頁面。已知侷限列於[比較頁面](topics/比較/index.md)。
