# البرنامج التعليمي

*خطوات تشغيل العرض التوضيحي على حاسوب محلي ومراجعة محفظة نموذجية.*

العرض التوضيحي نسخة كاملة من البرمجية، محمَّلة ببيانات مؤسسة وهمية هي Northgate Transport Authority. وجميع الأشخاص والخطط والأرقام والتواريخ وهمية، ويمكن تغيير البيانات بحرية.

**ملاحظة أمنية.** يثق العرض التوضيحي بمفتاح اختبار منشور. ويجب عدم تشغيله على شبكة مشتركة أو استخدامه مع بيانات حقيقية.

## المتطلبات

- [Git](https://git-scm.com/)
- [Podman](https://podman.io/) مع Compose

## الخطوة 1: تنزيل الشيفرة

```sh
git clone https://github.com/project-portfolio-management/project-portfolio-management.git
cd project-portfolio-management
```

## الخطوة 2: بدء العرض التوضيحي

```sh
POSTGRES_PASSWORD=demo podman compose --profile demo up -d --build --wait ui-demo
```

يبني هذا الأمر البرمجية، ويبدأ قاعدة البيانات، ويحمّل المحفظة الوهمية، ويبدأ الواجهة. ويستغرق البناء الأول وقتًا أطول من عمليات البناء اللاحقة.

## الخطوة 3: تسجيل الدخول

افتح <http://localhost:3000/ar-001/signin>، واترك العنوان `example@example.com` كما هو، واضغط **تسجيل الدخول إلى العرض التوضيحي**. لا تُرسل أي رسالة بريد إلكتروني.

الصفحة الأولى هي **جولة العرض التوضيحي**، وهي تسرد كل ميزة حسب المجموعة، مع وصف ورابط. ويذكر شريط أصفر في كل صفحة أن البيانات وهمية.

## الخطوة 4: مراجعة المحفظة

من الجولة، افتح **الخطط** لعرض المحفظة وبرامجها ومشاريعها. ثم افتح **لوحة متابعة المحفظة**.

## الخطوة 5: مراجعة مشروع واحد

افتح مشروع **North Line interlocking** من خلال مجموعة التسليم في الجولة. وراجع مخطط **Gantt** و**المسار الحرج** و**القيمة المكتسبة**.

## الخطوة 6: مراجعة العمل الشخصي

افتح **عملي** و**لوحة كانبان الخاصة بي**. والجلسة مسجَّلة باسم Example Person، الذي لديه مهام مفتوحة.

## الخطوة 7: مراجعة السعة وضبط البدء والتقارير

افتح **خريطة السعة الحرارية** لعرض الموارد المحجوزة فوق طاقتها. وافتح **طابور البدء**، حيث أدى حد العمل الجاري إلى تأخير برنامج واحد. وافتح **حزم المديرين**، وهي الملخص الشهري الذي يُجمَّد بعد إصداره.

## الخطوة 8: إيقاف العرض التوضيحي

يوقف هذا الأمر جميع الخدمات ويحذف بيانات العرض التوضيحي:

```sh
podman compose --profile demo down -v
```
