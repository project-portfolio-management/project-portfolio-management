# Управление портфелем проектов

*Реестр финансируемых работ с поиском дубликатов и рабочим пространством для управления проектами.*

Project Portfolio Management — программное обеспечение с открытым исходным кодом для учёта планов, которые финансирует организация, и управления работой в их рамках. Оно охватывает задачи, расписания, стоимость, ресурсы, риски и управление. Программа сравнивает планы, чтобы выявить возможные дубликаты, и показывает доказательства для каждого совпадения. Если показатель невозможно рассчитать, программа указывает причину.

## Основные преимущества

- **Единый реестр портфеля.** Портфели, программы, проекты и продукты используют один тип записи, и любой план может содержать другой. Отчётность строится по единому списку по всем подразделениям.
- **Поиск дубликатов.** Сопоставление сравнивает планы, внесённые под разными названиями, и показывает доказательства для каждого результата, чтобы рецензенты могли принять меры до того, как оба плана будут профинансированы.
- **Прослеживаемые показатели.** Отсутствующий показатель отображается вместе с причиной его отсутствия. План без оценки отображается как «не оценён».
- **Журнал аудита.** Каждое изменение фиксируется в журнале. Автор запроса на изменение не может его утвердить.
- **Контроль доступа.** Вход в систему включён по умолчанию, и в производственной среде сервис не запускается с отключённым входом.
- **Развёртывание и лицензирование.** Программа размещается самостоятельно и предлагается под пятью открытыми лицензиями. Работы можно импортировать из Jira, Asana и Microsoft Project.

## Функциональные области

- **Планы и сопоставление.** Рекурсивный реестр, объяснимый поиск дубликатов и объединение.
- **Выполнение.** Доски Канбан, диаграммы Ганта, календари, вехи, критический путь и критическая цепь.
- **Финансы.** Бюджеты, журнал финансирования, освоенный объём, а также риски стоимости и сроков.
- **Ресурсы.** Пулы навыков, тепловая карта загрузки и ключевые сотрудники.
- **Стратегия.** Приём работ, идеи, цели и ключевые результаты, сценарии.
- **Управление.** Риски, проблемы, шлюзовые проверки, эскалация и ежемесячные пакеты для директоров.

## Для кого предназначена программа

- **Офисы портфеля.** Отчётность по программам и проектам.
- **Руководители проектов и поставки.** Планирование, управление стоимостью и рисками.
- **Члены команды.** Личное представление назначенных работ.
- **Высшее руководство.** [Обзоры по ролям](for/) описывают, что программа предоставляет для каждой роли, её ограничения и решения, которые необходимо принять.

## Текущее состояние

Программа находится на ранней стадии. У неё один сопровождающий, нет стороннего аудита и соглашения о поддержке. Что потребуется для промышленной эксплуатации, по пунктам и с оценкой для каждого, описано на странице [путь к промышленной эксплуатации](path-to-production/index.md). Известные ограничения перечислены на [странице сравнений](topics/сравнения/index.md).

## Демонстрация

Локальная демонстрация использует вымышленное транспортное управление и требует Git и Podman. Шаги описаны в [руководстве](topics/руководство/index.md).
