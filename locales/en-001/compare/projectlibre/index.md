# Project Portfolio Management and ProjectLibre

*A single-user desktop application compared with a multi-user service.*

**Basis of this comparison.** ProjectLibre was not installed or run for this comparison. The description is general and may be out of date, and ProjectLibre's current documentation should be checked before a decision is made. Products are not scored. Statements about this project are taken from its repository.

## About ProjectLibre

An open-source desktop alternative to Microsoft Project, for one manager and one project.

## When ProjectLibre may be the better fit

- One manager is planning one project on a desktop computer
- Running a server is not an option

## When this project may be the better fit

- Many users need to work in one hosted, access-controlled service
- Many plans need to be nested and rolled up
- Risk, cost and governance are needed alongside the schedule

## Migration

The two projects share scheduling vocabulary: the eight constraint types, calendars, work contours, hammock activities and resource levelling. Microsoft Project XML is a possible exchange route, but it has not been tested.

## Project status

This project is at an early stage, with one maintainer and no third-party audit. Its own assessment is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing.
