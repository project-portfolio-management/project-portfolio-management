# 利点

*組織にとっての主な利点を、領域別にまとめました。*

## ポートフォリオの可視化

ポートフォリオの情報は、複数の場所に分散していることがよくあります。このソフトウェアでは、ポートフォリオ、プログラム、プロジェクト、プロダクトはすべて**計画**という一つのレコード種別です。どの計画も他の計画を任意の深さで含められるので、構造を組織に合わせられます。「プロジェクト」のようなラベルは説明用であり、計画に制限を加えるものではありません。

## 重複の削減

二つの部門が、同じ取り組みを別の名前で立ち上げることがあります。マッチャーは、計画を特定する属性（名前、目標、オーナー、スポンサー、親、期間、キーワード、識別子）を比較します。計画の種類を問わず動作し、一致ごとに根拠を示し、判断は人が行います。同じ計画の二つのレコードは統合できます。

## レポートの品質

- 欠けている数値は、「予測なし。理由は…」のように理由とともに表示されます。
- 評価されていない計画は「未評価」と表示されます。
- 人が記録した実行の確信度は、算出されたステータスの横に表示され、両者は区別されます。
- 非公開の計画は、すべてのユーザーについて、あらゆる合計と件数から除外されます。このルールはテストで確認されます。
- 各期間は、暦日か営業日かを明示します。

## 意思決定の記録

すべての変更が監査され、監査証跡はサービスを通じて改ざんできません。変更要求を起こした人は、それを承認できません。月次のディレクターパックは一度だけ下書きされ、指名された人が発行し、その後データベースによって凍結されます。訂正は、注記付きの新しい版として発行されます。

## セキュリティ

ログインは初期状態で有効であり、ログインを無効にしたままでは本番環境でサービスが起動しません。セキュリティヘッダー、レート制限、目標値を明記した復旧計画、情報ガバナンスパックがリポジトリに含まれています。

## 管理と可搬性

- **ライセンス。** ソフトウェアはオープンソースで、MIT、Apache-2.0、BSD-3-Clause、GPL-2.0、GPL-3.0、OGL-UK-3.0、CC-BY-NC-SA-4.0 から選べます。
- **ホスティング。** セルフホスト型です。PostgreSQL 上の一つの Rust サービスと、SvelteKit のインターフェースで構成されます。
- **データの取り込み。** Jira と Asana の CSV ファイルを、プレビューと除外理由の明示付きで取り込めます。Microsoft Project の XML は取り込みも書き出しもできます。
- **言語。** インターフェースは、右から左へ書くアラビア語を含む十のロケールで利用できます。翻訳は草稿であり、話者によるレビューを待っています。
