# 기능

*영역별 기능 요약. 등록부와 프로젝트 작업 공간은 하나의 기록을 공유합니다.*

## 계획과 일치 탐지

- 포트폴리오, 프로그램, 프로젝트 같은 선택적 이름표를 붙일 수 있는 하나의 재귀적 계획 모음
- 모든 종류의 계획에 걸친 설명 가능한 중복 일치 탐지
- 하나의 계획에 대한 두 기록을 단일 기록으로 병합

## 일상 업무

- 개인용 "내 업무" 페이지와 개인 칸반 보드
- 작업 보드, 달력, 마일스톤
- 저장된 보기와 포트폴리오 전체 검색

## 일정 관리

- 간트 차트와 작업 분류 체계
- Microsoft Project의 제약 조건 여덟 가지를 지원하는 주경로
- 기준선, 일정 건전성, 자원 평준화
- 버퍼, 버퍼 관리, 드럼을 갖춘 주사슬

## 자금

- 예산 항목, 비용, 자금 원장
- 획득가치
- 비용 위험, 그리고 비용과 일정을 함께 본 위험

## 인력과 역량

- 자원, 역할, 기술 풀, 가용성
- 역량 히트맵과 역량 약정
- 핵심 인력

## 전략과 접수

- 제안서와 아이디어를 포함한 업무 접수
- 목표, 핵심 결과, 핵심 지표
- 가정 분석 계획을 위한 시나리오와 진행 중인 업무를 제한하는 시작 대기열

## 거버넌스와 에스컬레이션

- 위험 등록부와 이슈
- 게이트 리뷰, 마일스톤 승인, 전환 결정
- 시간 제한이 있는 예외와 에스컬레이션 경로
- 월간 이사 패킷
- 조직이 정의하는 이슈 유형과 상태. 상태 전이는 이슈 유형별로 다를 수 있고 역할로 제한할 수 있습니다.

## 보안과 운영

- 기본 로그인, 그리고 Keycloak을 통한 Microsoft Entra ID를 포함한 외부 ID 공급자 로그인
- 서비스를 통해 바꿀 수 없는 감사 추적
- 요청 속도 제한과 보안 헤더
- 검증된 복원 훈련을 갖춘 백업 및 복원 도구

## 아직 제공되지 않는 것

현재 버전에는 다음이 없습니다.

- 모바일 앱 또는 데스크톱 애플리케이션
- 실시간 공동 편집
- 변경 요청을 작성하거나 결정하는 화면. 변경 요청은 서비스를 통해서만 이용할 수 있습니다.
- 이사 패킷용 PDF 또는 화면(데이터로만 제공됨)과 계획된 여러 패킷 항목

[프로젝트 백로그](https://github.com/project-portfolio-management/project-portfolio-management/blob/main/tasks.md)에 각 항목의 한계가 기록되어 있습니다.
