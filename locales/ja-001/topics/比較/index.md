# 比較

*このソフトウェアが他の製品とどう関係するかの概要。*

以下の製品は目的が異なり、採点はしていません。これらの記述は、各プロジェクトが公開している資料に基づいています。**他の製品はインストールも実行もしておらず**、その後に変更されている可能性があります。判断の前に、最新の製品ドキュメントを確認してください。

| プロジェクト | 概要 | このプロジェクトとの違い |
| --- | --- | --- |
| [Leantime](https://github.com/leantime/leantime) | プロジェクトマネージャーではない人のためのプロジェクト管理 | このプロジェクトには、ポートフォリオオフィスが使うスケジュール、コスト、ガバナンスの機能も含まれます |
| [Redmine](https://www.redmine.org/) | 組織が課題タイプ、ステータス、役割を定義できる、設定可能な汎用トラッカー | 課題タイプ、ステータス、ワークフローは組織が定義します。役割は課題の権限を持ち、計画ごとに付与され、本人のサインインが許す範囲に収まります。[Redmine との比較](../../../en-001/compare/redmine/index.md)（英語）を参照 |
| Huly Platform（フォークの Platform Collective 経由） | 多数のサービスから成るビジネスアプリケーションのフレームワーク | Huly は複数サービスのプラットフォームです。このプロジェクトは PostgreSQL 上の一つのサービスです |
| [ProjectLibre](https://sourceforge.net/p/projectlibre/) | Microsoft Project に代わるデスクトップ製品。一人のマネージャーと一つのプロジェクト向け | このプロジェクトは、アクセス制御を備えたホスト型のマルチユーザーサービスです |

## 相互運用性

- **Jira と Asana:** CSV の取り込み。プレビューと、除外したすべてのものの理由を明示します。
- **Microsoft Project:** MSPDI XML の取り込みと書き出し。タスク、アウトライン、日付、期間、制約、依存関係、カレンダーを扱います。担当者、リソース、ベースラインは対象外で、ファイルにその旨が記録されます。

## 設計上の違い

- **理由の明示。** 欠けている数値は、「予測なし。理由は…」のように理由とともに表示されます。
- **説明可能な重複検出。** 照合はあらゆる種類の計画にわたって動作し、根拠を示します。
- **セキュリティの初期設定。** ログインは初期状態で有効で、セキュリティ関連の資料がリポジトリに含まれています。
- **明示的な期間。** 各期間は暦日か営業日かで示されます。
- **記録された制約。** バックログは各項目の制約を記録しています。

## 既知の制約

- モバイルアプリもデスクトップアプリもありません。
- リアルタイム共同編集はありません。
- メンテナーは一人で、本番での実績は限られ、第三者による監査はありません。
- 公開している負荷テストは一台のマシンで実施しました。桁の目安を示すものであり、キャパシティ計画ではありません。
- 翻訳は草稿であり、レビューを待っています。
- 変更要求を起案・決定する画面はありません。
- プラグインやマーケットプレイスのエコシステムはありません。
