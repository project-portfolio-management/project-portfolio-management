# Сравнения

*Краткое описание того, как программа соотносится с другими продуктами.*

Перечисленные ниже продукты служат разным целям и не оцениваются баллами. Эти заметки основаны на публичных материалах каждого проекта. **Ни один другой продукт не устанавливался и не запускался**, и каждый мог измениться с тех пор. Перед принятием решения следует проверить актуальную документацию продукта.

| Проект | Что это | Чем отличается этот проект |
| --- | --- | --- |
| [Leantime](https://github.com/leantime/leantime) | Управление проектами для тех, кто не является руководителем проектов | Этот проект также включает функции планирования, учёта стоимости и управления, которыми пользуется офис портфеля |
| [Redmine](https://www.redmine.org/) | Настраиваемая универсальная система отслеживания с определяемыми организацией типами задач, статусами и ролями | Типы задач, статусы и рабочие процессы определяет организация. Роли несут права на задачи, назначаемые по каждому плану, в пределах того, что разрешает вход человека. См. [сравнение с Redmine](../../../en-001/compare/redmine/index.md) |
| Huly Platform (через ответвление Platform Collective) | Каркас бизнес-приложений на множестве сервисов | Huly — многосервисная платформа. Этот проект — один сервис поверх PostgreSQL |
| [ProjectLibre](https://sourceforge.net/p/projectlibre/) | Настольная альтернатива Microsoft Project для одного руководителя и одного проекта | Этот проект — размещаемый многопользовательский сервис с контролем доступа |

## Совместимость

- **Jira и Asana:** импорт CSV с предварительным просмотром и указанием причины для всего пропущенного.
- **Microsoft Project:** импорт и экспорт XML MSPDI, охватывающие задачи, структуру, даты, длительности, ограничения, зависимости и календарь. Исполнители, ресурсы и базовые планы исключаются, и файл это фиксирует.

## Отличия в проектировании

- **Указание причин.** Отсутствующий показатель отображается с причиной, например «нет прогноза, потому что…».
- **Объяснимый поиск дубликатов.** Сопоставление работает по всем типам планов и показывает свои доказательства.
- **Безопасные настройки по умолчанию.** Вход включён по умолчанию, а материалы по безопасности входят в репозиторий.
- **Явные длительности.** Каждая длительность указана в календарных или рабочих днях.
- **Зафиксированные ограничения.** Бэклог фиксирует ограничения каждого пункта.

## Известные ограничения

- Нет мобильного или настольного приложения.
- Нет совместного редактирования в реальном времени.
- Один сопровождающий, ограниченная история промышленной эксплуатации и отсутствие стороннего аудита.
- Опубликованное нагрузочное испытание проводилось на одной машине. Оно указывает порядок величины и не является планом ёмкости.
- Переводы являются черновиками, ожидающими проверки.
- Нет экрана для составления запросов на изменение и принятия по ним решений.
- Нет экосистемы плагинов и торговой площадки.

Дополнительные сведения приведены в [заметках о сравнении](https://github.com/project-portfolio-management/project-portfolio-management/blob/main/COMPARISONS.md). Исправления можно направить в виде обращения с указанием источника.
