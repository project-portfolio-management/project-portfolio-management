# 致資訊長

*資訊長：整合、身份、資料、託管，以及您將被要求提交的資訊。*

## 身份與訪問

- 登入**預設強制啟用**；沒有令牌驗證金鑰，服務拒絕啟動；在生產環境中關閉登入也拒絕啟動。
- 透過身份提供方（包括 Microsoft Entra ID）登入；多因素認證由提供方負責（[登入指南](../../../../operations/sign-in-with-entra.md)）。
- 授權基於令牌屬性（例如 `access`、`directorpack`、`confidence`）和屬性策略。私有計劃不出現在任何彙總中；處理標記會對高於呼叫者許可級別的計劃隱藏，管理員也不例外。
- 訪問私有計劃的緊急通道需要具備資格、陳述理由、最長四小時，並通知第二個人。
- 管理員可以列出現有的訪問授權（用於複核認證），並匯出或假名化某個人的資料。

## 資料與整合

| 主題 | 立場 |
|---|---|
| 持有的資料 | 計劃、任務、風險、預算、里程碑、工時與成本記錄；人員為不透明引用，而非姓名。按設計不含患者資料和特殊類別資料 |
| 清單 | 每個個人資料列都列在[個人資料清單](../../../../governance/personal-data-inventory.csv)中；由測試保證其與資料庫結構一致 |
| 介面 | REST 與推匯出的 OpenAPI 文件；批次匯入匯出；日曆訂閱；僅限公共 `https` 目的地的出站事件和 webhook |
| 備份 | 指令碼化備份，經過測試的恢復，可選加密，明確的恢復目標（[備份與恢復](../../../../operations/backup-and-restore.md)） |
| 託管 | 容器映象和 `compose.yaml`；軟體自身不做任何傳輸，所以資料所在地取決於您的託管選擇 |

## 您必須彌補的差距

- 滲透測試、獨立程式碼評審和認證：均未進行。
- 保留期只部分得到執行；必須安排清理（見[保留期計劃](../../../../governance/retention-schedule.md)）。
- 資料主體工具找到的是引用，找不到鍵入自由文字或上傳檔案中的姓名。
- 審計記錄無法抵禦資料庫管理員的篡改。
