# Project Portfolio Management and ProjectLibre

*On your desktop, or shared by everyone?*

**How this page was written.** Nobody installed or ran ProjectLibre for this comparison. Its description is general, and it may be out of date, so please check ProjectLibre's own documentation. Different products solve different problems, so nothing here is scored. The facts about this project come from its own repository.

## What ProjectLibre is

An open-source desktop alternative to Microsoft Project, for one manager and one project.

## ProjectLibre may suit you better if

- You are one manager planning one project, on your own desktop
- You do not want to run a server

## This project may suit you better if

- You want many people in one hosted, access-controlled service
- You want many plans, nested and rolled up
- You want risk, cost and governance alongside the schedule

## Moving your work

This project shares its scheduling vocabulary: the eight constraint types, calendars, work contours, hammock activities and resource levelling. Microsoft Project XML is the likely route between them, but that route has not been tried.

## Before you decide

This project is young, with one maintainer and no third-party audit. Its own verdict is that it is ready for a controlled pilot on non-clinical, non-secret data, and not ready for unsupervised production use. It has no mobile app and no real-time co-editing. Read [where it is behind](../../topics/comparisons/index.md#where-it-is-behind).
