# 功能

*按领域列出的功能摘要。登记册和项目工作区共用同一条记录。*

## 计划与匹配

- 一个可递归的计划集合，可选用组合、项目集或项目等标签
- 跨所有类型计划的可解释重复匹配
- 将同一计划的两条记录合并为一条

## 日常工作

- 个人“我的工作”页面和个人看板
- 任务板、日历和里程碑
- 已保存视图，以及跨组合搜索

## 进度安排

- 甘特图和工作分解结构
- 关键路径，支持 Microsoft Project 的八种约束类型
- 基线、进度健康度和资源平衡
- 关键链，包括缓冲、缓冲管理和鼓

## 资金

- 预算行、成本和资金台账
- 挣值
- 成本风险，以及成本与进度的综合风险

## 人员与产能

- 资源、角色、技能池和可用性
- 产能热力图和产能承诺
- 关键人员

## 战略与工作受理

- 工作受理，包括提案和创意
- 目标、目标与关键成果，以及关键指标
- 用于假设规划的情景，以及限制在制品的启动队列

## 治理与升级

- 风险登记册和问题
- 阶段门评审、里程碑签核和切换决策
- 带计时的例外事项，以及升级路径
- 每月董事报告包

## 安全与运维

- 默认登录，可通过外部身份提供方登录，包括通过 Keycloak 使用 Microsoft Entra ID
- 无法通过服务更改的审计记录
- 速率限制和安全标头
- 备份和恢复工具，以及经过测试的恢复演练

## 尚不可用

当前版本不包括：

- 移动应用或桌面应用
- 实时协同编辑
- 用于起草或裁决变更请求的界面（变更请求目前只能通过服务使用）
- 董事报告包的 PDF 或界面（目前以数据形式提供），以及若干计划中的章节
