# 致首席風險官

*首席風險官：軟體幫助您看到的風險，以及使用它的風險。*

## 它幫助您管理的風險

- **風險、問題和變更請求**按計劃記錄；跨可讀計劃的問題登記冊；帶職責分離的變更請求。
- **交付信心與例外：** 陳述的信心與計算所得的 RAG 分開，二者相差兩級時標出，歷史只追加；48 小時例外計時在評級惡化時不會重新開始，只有記錄在案的決定才能關閉。
- **如實表示缺失：** 缺失的資料顯示為「未評估」或附理由的空值，絕不顯示為綠色或零。
- **凍結、有版本的月度簡報包，**因此可以日後按簽發時的原樣出示曾告知董事的內容。

## 使用它的風險（專案自己的登記冊）

| 風險 | 狀態 |
|---|---|
| 沒有滲透測試、第三方審計或認證 | 未決：由買方委託（[保證清單](../../../../governance/assurance-checklist.md)） |
| 只對部分資料執行保留期 | 未決；必須安排清理 |
| 資料主體工具不搜尋自由文字、附件或備份 | 未決 |
| 審計記錄可被資料庫管理員破壞；沒有雜湊鏈 | 已在 [DPIA](../../../../governance/dpia.md) 中說明 |
| 處理標記只隱藏和標註，不加密 | 已說明 |
| 附件掃描需要部署方執行掃描器 | 未決 |
| 單一維護者，無服務水平協議 | 未決 |
| 譯文為草稿 | 未決 |
| 僅限非臨床；沒有臨床安全案例 | 請勿輸入臨床內容 |

## 軟體強制執行的控制

預設登入、速率限制、嚴格的安全標頭、空閒會話超時（30 分鐘）和硬性會話上限、僅限公共 `https` 的出站目的地、校驗簽名的附件、不可變的審計行、帶審計的緊急通道。每一項都有測試覆蓋，見[通往生產之路](../../path-to-production/index.md)。

## 屬於您的決定

試點的風險偏好；例外視窗（預設 48 小時）；本部署獲得保證的標記級別；誰複核訪問清單以及多久一次。
