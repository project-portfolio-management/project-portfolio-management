# Преимущества

*Основные преимущества для организации по областям.*

## Прозрачность портфеля

Информация о портфеле часто хранится в нескольких местах. В этой программе каждый портфель, программа, проект и продукт — это один тип записи, называемый **планом**. Любой план может содержать любой другой, на любую глубину, поэтому структура может соответствовать организации. Метка, например «Проект», носит описательный характер и не накладывает на план никаких ограничений.

## Сокращение дублирования

Два подразделения могут утвердить одну и ту же инициативу под разными названиями. Сопоставление сравнивает признаки, идентифицирующие план: название, цели, владельца, спонсора, родителя, сроки, ключевые слова и идентификаторы. Оно работает по всем типам планов и показывает доказательства для каждого совпадения, а решение принимает человек. Две записи одного плана можно объединить.

## Качество отчётности

- Отсутствующий показатель отображается с причиной, например «нет прогноза, потому что…».
- План без оценки отображается как «не оценён».
- Уверенность в выполнении, указанная людьми, отображается рядом с рассчитанным состоянием, и эти два показателя хранятся раздельно.
- Закрытые планы исключаются из всех итогов и подсчётов для всех пользователей. Эти правила проверяются тестами.
- Каждая длительность указывает, выражена ли она в календарных или рабочих днях.

## Записи о решениях

Каждое изменение фиксируется в журнале аудита, и журнал нельзя изменить через сервис. Автор запроса на изменение не может его утвердить. Ежемесячный пакет для директора составляется один раз, выпускается назначенным лицом, после чего замораживается базой данных. Исправление выпускается как новая версия с примечанием.

## Безопасность

Вход в систему включён по умолчанию, и в производственной среде сервис не запускается с отключённым входом. Заголовки безопасности, ограничение частоты запросов, план восстановления с заявленными целевыми показателями и пакет документов по управлению информацией включены в репозиторий.

## Контроль и переносимость

- **Лицензирование.** Программа имеет открытый исходный код под одной из лицензий на выбор: MIT, Apache-2.0, BSD-3-Clause, GPL-2.0, GPL-3.0, OGL-UK-3.0 или CC-BY-NC-SA-4.0.
- **Размещение.** Программа размещается самостоятельно: один сервис на Rust поверх PostgreSQL с интерфейсом на SvelteKit.
- **Импорт данных.** Можно импортировать CSV-файлы из Jira и Asana с предварительным просмотром и указанием причины для всего исключённого. Microsoft Project XML можно импортировать и экспортировать.
- **Языки.** Интерфейс доступен на десяти локалях, включая арабский с письмом справа налево. Переводы являются черновиками, ожидающими проверки носителями языка.
