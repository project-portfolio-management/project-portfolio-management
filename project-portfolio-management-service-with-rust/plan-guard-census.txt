# Every mounted route outside the plan guard, and how it treats a plan the caller cannot read. privacy_mw covers only
# /api/plans/{pid} and what is beneath it, so a route anywhere else decides for itself, and a new one must be listed here
# (src/controllers/plan_access.rs test every_route_outside_the_guard_is_declared). This is a declaration, not a proof:
# tests/private_routes.rs and tests/private_aggregates.rs exercise what they name.
#
# checks     reaches a plan's record by its own pid or a field, and answers as for one that does not exist
# filters    spans plans and leaves out what the caller cannot read
# own        only the caller's own records
# admin      an administrator or a named area's right; full by design
# no-plan    holds no plan's data
# left-open  reviewed, and left as a decision recorded in CHANGELOG.md
