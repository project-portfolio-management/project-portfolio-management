# 致首席运营官

*首席运营官：您日常管理的事务、软件为交付所做的事，以及运行它需要什么。*

## 它为运营做什么

- **交付计划与控制：** 计划、任务、依赖关系、关键路径计算、跨计划的里程碑、迭代与阶段、燃尽图和流动指标。
- **产能：** 分配、可用性、休假与非工作时段、资源角色，以及推导出的工作量和利用率。（面向董事简报包、按技能池和月份划分的产能热力图尚未构建：`DP-10`。）
- **工时与成本：** 工时表、已记录的工时、成本费率（限财务查看）、预算和推导出的成本。
- **治理流程：** 问题登记册、带职责分离的变更请求（提出者不能批准）、审批、评审、入职/调动/离职案例。
- **例外：** 红色或琥珀红的交付信心会开启一个例外，须在 48 小时内（窗口可配置，1 至 720 小时）给出原因、所需的决定、具名负责人和决定截止日期。违约显示在董事简报包和 `GET /api/exceptions` 中。

## 运行它需要什么

| 需要 | 详情 |
|---|---|
| 服务 | 一个 Rust 服务、PostgreSQL 18、可选的 Redis（生产缓存、可选的共享会话）、一个 SvelteKit 界面 |
| 运行手册 | [运维包](../../../../operations/README.md)：部署、运行手册、备份与恢复、恢复目标、升级与迁移 |
| 定时任务 | 没有任何任务会自行调度。保留期清理、例外违约通知等任务须由您的运维人员放入调度器 |
| 支持 | 一位维护者，没有服务水平协议；请自行预算一线支持 |

## 了解其局限

- 数千个任务的计划调度较慢；超过 5,000 个任务时，完整结果会被拒绝，除非明确请求（`?full=true` 或 `?only=critical`）。数据和注意事项见 [`BENCHMARKS.md`](../../../../BENCHMARKS.md)；它们只是来自一台机器的数量级，不代表容量。
- 工作区的大部分有界面，但变更请求、问题、简报包和交付信心**尚无**界面；目前只能通过 API 使用。

## 属于您的决定

每个例外由谁负责，谁签发月度简报包（节奏与提醒属于 `DP-12`，尚未构建），以及例外规则支撑怎样的评审周期。
