# Project Portfolio Management and Smartsheet

*A spreadsheet-style tool compared with a purpose-built registry.*

**Basis of this comparison.** Smartsheet was not installed or run for this comparison. The description is general and may be out of date, and Smartsheet's current documentation should be checked before a decision is made. Products are not scored. Statements about this project are taken from its repository.

## About Smartsheet

A hosted work management tool with a spreadsheet-like interface.

## When Smartsheet may be the better fit

- Users prefer to work in rows and columns
- A hosted service with vendor support is preferred
- Flexible sheets are preferred to a fixed vocabulary

## When this project may be the better fit

- Every plan needs to be one record type, with plans nested inside each other
- Duplicate plans need to be identified
- Private plans need to be excluded from all totals and counts
- Self-hosting is required

## Migration

There is **no Smartsheet importer**. Tab-separated rows of tasks can be pasted into a task board.

## Project status

This project is at an early stage, with one maintainer and no third-party audit. What production use would take, item by item with an estimate for each, is on the [path to production](../../path-to-production/index.md) page. It has no mobile app and no real-time co-editing.
