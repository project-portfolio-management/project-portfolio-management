# Для директора по информационной безопасности

*Директор по информационной безопасности: что обеспечивает программа, что проверил проект и что вы должны проверить и эксплуатировать сами.*

## Что обеспечивает программа

| Область | Поведение |
|---|---|
| Аутентификация | Вход включён по умолчанию. Сервис не запустится без ключей проверки токенов и не запустится в производственной среде с отключённым входом. Вход через поставщика удостоверений, например Microsoft Entra ID; многофакторная аутентификация остаётся за поставщиком ([руководство по входу](../../../../operations/sign-in-with-entra.md)) |
| Авторизация | Политика на основе атрибутов токена. Закрытые планы исключены из всех сводных показателей для всех; грифы обращения скрывают планы выше допуска вызывающего, включая администраторов |
| Аварийный доступ | Доступ к закрытым планам требует права на него, указанной причины, не более четырёх часов и уведомления второго лица; каждый запрос фиксируется в журнале |
| Сеансы | Тайм-аут простоя (по умолчанию 30 минут) и жёсткий предел длительности сеанса |
| Передача и браузер | Заголовки безопасности, строгая политика безопасности содержимого, список разрешённых источников CORS, ограничение частоты запросов для каждого вызывающего |
| Исходящие запросы | Адреса назначения, указанные пользователем, ограничены публичными адресами `https` |
| Загрузки | Содержимое должно соответствовать заявленному типу; программы отклоняются; необязательная проверка `clamd` при сбое блокирует файл |
| Аудит | Журнал аудита в базе данных отклоняет изменение и удаление |
| Замороженные записи | Выпущенные пакеты директоров и оценки уверенности в выполнении неизменяемы или допускают только дописывание благодаря триггеру базы данных |
| Цепочка поставок | `cargo deny`, перечень компонентов программного обеспечения, подтверждение происхождения сборки при выпуске, [политика безопасности](../../../../SECURITY.md) |

## Что не сделано

- Нет тестирования на проникновение, стороннего аудита, независимой проверки кода или сертификации.
- Нет встроенного сканера вредоносных программ; перехватчик `clamd` проверялся только на заменителе.
- Журнал аудита может быть обойдён администратором базы данных; цепочки хешей нет.
- Грифы обращения скрывают и маркируют; они не шифруют, а гриф не проставляется в создаваемых файлах.
- Сеансы хранятся в памяти, если не настроен Redis.
- Инструмент для запросов субъектов данных находит ссылки, но не имена, введённые в свободный текст, загруженные файлы или резервные копии.

## Эксплуатация

Резервные копии имеют проверенное восстановление, необязательное шифрование и заявленные целевые показатели восстановления ([пакет эксплуатации](../../../../operations/README.md)). [Руководство по эксплуатации](../../../../operations/runbook.md) описывает технические шаги при инциденте; процесс обработки инцидентов и утечек — ваш. О найденной уязвимости сообщайте в частном порядке, как описано в [SECURITY.md](../../../../SECURITY.md); цели — подтверждение в течение 5 рабочих дней, а не гарантии.

## Решения, которые принадлежат вам

Кто проводит тестирование на проникновение и когда; условный доступ и сопоставление ролей у поставщика удостоверений; для какого уровня грифа развёртывание прошло проверку; сканер за перехватчиком вложений; как часто проводится повторная сертификация доступа.
