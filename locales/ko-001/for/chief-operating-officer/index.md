# 최고운영책임자(COO)를 위한 안내

*최고운영책임자: 날마다 운영하는 업무, 소프트웨어가 수행에 해 주는 일, 그리고 소프트웨어를 운영하는 데 필요한 것.*

## 운영에 해 주는 일

- **수행 계획과 통제:** 계획, 작업, 의존 관계, 주경로 계산, 계획에 걸친 마일스톤, 스프린트와 단계, 번다운과 흐름 지표.
- **역량:** 배정, 가용성, 휴가와 비근무 기간, 자원 역할, 파생된 업무량과 가동률. (이사 패킷용 기술 풀·월별 역량 히트맵은 아직 만들어지지 않았습니다. `DP-10`.)
- **시간과 비용:** 근무 시간표, 기록된 시간, 비용 단가(재무 제한), 예산, 파생된 비용.
- **거버넌스 흐름:** 이슈 등록부, 직무 분리가 적용되는 변경 요청(요청자는 승인할 수 없음), 승인, 검토, 입사·이동·퇴사 사례.
- **예외:** 적색 또는 황적색 수행 신뢰도는 원인, 필요한 결정, 지정된 소유자, 48시간 이내의 결정 기한(기간 설정 가능, 1~720시간)이 필요한 예외를 엽니다. 위반은 이사 패킷과 `GET /api/exceptions`에 나타납니다.

## 운영에 필요한 것

| 필요 | 세부 사항 |
|---|---|
| 서비스 | Rust 서비스 하나, PostgreSQL 18, 선택적 Redis(운영 환경 캐시, 선택적 공유 세션), SvelteKit UI |
| 운영 지침서 | [운영 패킷](../../../../operations/README.md): 배포, 운영 지침서, 백업과 복원, 복구 목표, 업그레이드와 마이그레이션 |
| 예약 작업 | 스스로 예약되는 것은 없습니다. 보존 삭제, 예외 위반 알림 같은 작업은 운영자가 스케줄러에 올려야 합니다 |
| 지원 | 유지 관리자 한 명, SLA 없음. 자체 1차 지원 예산을 잡아 두세요 |

## 한계를 알아 두세요

- 수천 개 작업의 계획은 일정 계산이 느립니다. 작업이 5,000개를 넘으면 요청하지 않는 한 전체 응답이 거부됩니다(`?full=true` 또는 `?only=critical`). 수치와 유의 사항은 [`BENCHMARKS.md`](../../../../BENCHMARKS.md)에 있으며, 한 대의 기계에서 얻은 대략적인 규모일 뿐 용량이 아닙니다.
- 작업 공간의 많은 부분에 화면이 있지만 변경 요청, 이슈, 패킷, 수행 신뢰도에는 **아직 없습니다.** 지금은 API로만 쓸 수 있습니다.

## 직접 내려야 할 결정

각 예외의 소유자가 누구인지, 월간 패킷을 누가 발행하는지(주기와 알림은 `DP-12`이며 만들어지지 않았음), 예외 규칙이 어떤 검토 주기로 이어지는지.
