# Beneficios

*Los principales beneficios para una organización, por área.*

## Visibilidad de la cartera

La información de la cartera suele estar repartida en varios lugares. En este software, cada cartera, programa, proyecto y producto es un único tipo de registro, llamado **plan**. Cualquier plan puede contener a cualquier otro, a cualquier profundidad, de modo que la estructura puede reflejar la de la organización. Una etiqueta como «Proyecto» es descriptiva y no impone ninguna restricción a un plan.

## Reducción de duplicados

Dos departamentos pueden dar de alta la misma iniciativa con nombres distintos. El comparador contrasta los atributos que identifican a un plan: nombre, objetivos, responsable, patrocinador, plan superior, plazo, palabras clave e identificadores. Funciona con todos los tipos de plan y muestra la evidencia de cada coincidencia, y la decisión la toma una persona. Dos registros de un mismo plan se pueden fusionar.

## Calidad de los informes

- Una cifra faltante se muestra con su motivo, por ejemplo «sin pronóstico, porque…».
- Un plan sin evaluación se muestra como «sin evaluar».
- La confianza de entrega que registran las personas se muestra junto al estado calculado, y ambos se mantienen separados.
- Los planes privados se excluyen de todos los totales y recuentos para todos los usuarios. Las pruebas comprueban esta regla.
- Cada duración indica si está en días naturales o en días hábiles.

## Registro de decisiones

Cada cambio queda auditado, y el registro de auditoría no se puede alterar a través del servicio. Quien presenta una solicitud de cambio no puede aprobarla. Un paquete mensual de dirección se redacta una vez, lo emite una persona identificada y después la base de datos lo congela. Una corrección se emite como una versión nueva con una nota.

## Seguridad

El inicio de sesión está activado de forma predeterminada, y el servicio no arranca en producción con el inicio de sesión desactivado. El repositorio incluye encabezados de seguridad, limitación de tasa, un plan de recuperación con objetivos declarados y un paquete de gobernanza de la información.

## Control y portabilidad

- **Licencias.** El software es de código abierto, con la opción de MIT, Apache-2.0, BSD-3-Clause, GPL-2.0, GPL-3.0, OGL-UK-3.0 o CC-BY-NC-SA-4.0.
- **Alojamiento.** El software se aloja por cuenta propia: un servicio en Rust sobre PostgreSQL, con una interfaz en SvelteKit.
- **Importación de datos.** Se pueden importar archivos CSV de Jira y Asana, con una vista previa y el motivo declarado de todo lo que se excluye. El XML de Microsoft Project se puede importar y exportar.
- **Idiomas.** La interfaz está disponible en diez configuraciones regionales, incluido el árabe, que se escribe de derecha a izquierda. Las traducciones son borradores pendientes de revisión por hablantes.
