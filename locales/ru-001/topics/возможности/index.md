# Возможности

*Функциональное резюме по областям. Реестр и рабочее пространство проекта используют одну запись.*

## Планы и сопоставление

- Одна рекурсивная коллекция планов с необязательной меткой, например «Портфель», «Программа» или «Проект»
- Объяснимое сопоставление дубликатов по всем видам планов
- Объединение двух записей одного плана в одну запись

## Повседневная работа

- Личная страница «Моя работа» и личная доска Канбан
- Доски задач, календари и вехи
- Сохранённые представления и поиск по портфелю

## Планирование

- Диаграммы Ганта и иерархическая структура работ
- Критический путь с восемью типами ограничений Microsoft Project
- Базовые планы, состояние расписания и выравнивание ресурсов
- Критическая цепь с буферами, управлением буферами и барабаном

## Деньги

- Статьи бюджета, затраты и журнал финансирования
- Освоенный объём
- Риск стоимости, а также риск стоимости и сроков вместе

## Люди и ёмкость

- Ресурсы, роли, пулы навыков и доступность
- Тепловая карта загрузки и обязательства по ёмкости
- Ключевые сотрудники

## Стратегия и приём работ

- Приём работ с предложениями и идеями
- Цели, задачи и ключевые результаты, а также ключевые показатели
- Сценарии для планирования «что, если» и очередь запуска, ограничивающая объём незавершённой работы

## Управление и эскалация

- Реестр рисков и проблемы
- Шлюзовые проверки, подписание вех и решения о переходе
- Исключения с таймером и путь эскалации
- Ежемесячные пакеты для директоров
- Определяемые организацией типы задач и статусы, с переходами между статусами, которые могут различаться по типу задачи и ограничиваться по роли

## Безопасность и эксплуатация

- Вход по умолчанию, с входом через внешнего поставщика удостоверений, включая Microsoft Entra ID через Keycloak
- Журнал аудита, который нельзя изменить через сервис
- Ограничение частоты запросов и заголовки безопасности
- Инструменты резервного копирования и восстановления с проверенной процедурой восстановления

## Пока недоступно

Текущая версия не включает:

- Мобильное или настольное приложение
- Совместное редактирование в реальном времени
- Экран для составления запросов на изменение и принятия по ним решений, которые доступны только через сервис
- PDF или экран для пакетов директоров, которые предоставляются в виде данных, и несколько запланированных разделов пакета

[Бэклог проекта](https://github.com/project-portfolio-management/project-portfolio-management/blob/main/tasks.md) фиксирует ограничения каждого пункта.
