# News

## 10 October 2026: a secure, operable, multilingual release candidate

The project reached a point where it can be run by someone else:

- It **builds from a fresh clone**, has continuous integration, and has a
  tag-driven release workflow.
- It is **secure by default**: login enforced, security headers, rate limiting.
- It ships an **operations pack** (backup and a tested restore, stated recovery
  targets, an upgrade guide, a runbook) and an **information governance pack**
  (a starting point for a data protection impact assessment, retention schedule
  and accessibility statement).
- It supports **sign-in with Microsoft Entra ID** through OpenID Connect.
- Every page can be shown in **Welsh**. This is a draft awaiting a professional
  translator's review, and says so.
- An **issues register** is in; **change requests** are the next feature.

What it is not yet: audited by a third party, load-tested, or released as 1.0.
See [BENCHMARKS.md](BENCHMARKS.md) and [AI_STATEMENT.md](AI_STATEMENT.md).
