# الميزات

*ملخص وظيفي حسب المجال. يتشارك السجل ومساحة عمل المشروع سجلًا واحدًا.*

## الخطط والمطابقة

- مجموعة عودية واحدة من الخطط، مع تسمية اختيارية مثل محفظة أو برنامج أو مشروع
- مطابقة قابلة للتفسير لكشف التكرارات عبر كل أنواع الخطط
- دمج سجلين لخطة واحدة في سجل واحد

## العمل اليومي

- صفحة شخصية بعنوان «عملي» ولوحة كانبان شخصية
- لوحات المهام والتقاويم والمعالم
- طرق العرض المحفوظة، والبحث عبر المحفظة

## الجدولة

- مخططات Gantt وهيكل تقسيم العمل
- المسار الحرج، مع أنواع القيود الثمانية في Microsoft Project
- خطوط الأساس وسلامة الجدول الزمني وتسوية الموارد
- السلسلة الحرجة، مع الاحتياطيات وإدارة الاحتياطيات والطبل

## المال

- بنود الميزانية والتكاليف ودفتر التمويل
- القيمة المكتسبة
- مخاطر التكلفة، ومخاطر التكلفة والجدول الزمني معًا

## الأشخاص والسعة

- الموارد والأدوار ومجمّعات المهارات والتوافر
- خريطة السعة الحرارية والتزامات السعة
- الأشخاص الرئيسيون

## الاستراتيجية والاستقبال

- استقبال الأعمال، مع المقترحات والأفكار
- الأهداف، والأهداف والنتائج الرئيسية، والمقاييس الرئيسية
- السيناريوهات للتخطيط الافتراضي، وطابور بدء يحد من العمل الجاري

## الحوكمة والتصعيد

- سجل المخاطر والمشكلات
- مراجعات البوابات واعتماد المعالم وقرارات الانتقال
- الاستثناءات مع مؤقت، ومسار للتصعيد
- حزم المديرين الشهرية
- أنواع مشكلات وحالات تحددها المؤسسة، مع انتقالات حالة يمكن أن تختلف حسب نوع المشكلة وأن تُقيَّد حسب الدور

## الأمان والعمليات

- تسجيل الدخول افتراضيًا، مع تسجيل الدخول عبر مزوّد هوية خارجي، بما في ذلك Microsoft Entra ID من خلال Keycloak
- سجل تدقيق لا يمكن تعديله من خلال الخدمة
- تحديد معدل الطلبات وترويسات الأمان
- أدوات النسخ الاحتياطي والاستعادة، مع تدريب استعادة مختبَر

## غير متاح بعد

لا يتضمن الإصدار الحالي ما يلي:

- تطبيق للهاتف المحمول أو تطبيق لسطح المكتب
- التحرير المشترك في الوقت الفعلي
- شاشة لصياغة طلبات التغيير أو البت فيها، وهي متاحة من خلال الخدمة فقط
- ملف PDF أو شاشة لحزم المديرين، وهي تُسلَّم بوصفها بيانات، وعدة أقسام مخطط لها من الحزم

يسجل [سجل أعمال المشروع المتراكمة](https://github.com/project-portfolio-management/project-portfolio-management/blob/main/tasks.md) حدود كل بند.
