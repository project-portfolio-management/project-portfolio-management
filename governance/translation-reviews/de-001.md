## How a review is done

1. Run the export (above); each row is `key`, `english`, `translation` and three columns for the reviewer:
   `reviewed_by`, `reviewed_on`, `verdict` (`accepted`, `changed` or `rejected`).
2. Correct the `translation` column where needed and fill in the three review columns. Placeholders such as
   `{count}` or `{name}` must be kept exactly: `tests/unit/catalogue-coverage.test.ts` fails if one is lost.
3. A maintainer copies each changed value back to its catalogue (the page file for keys beginning `p.` and `c.`,
   the locale's block for the others), runs the tests, and re-runs the export, which keeps the review columns of
   unchanged rows.
4. When every row has a verdict, update the table above and add a row to the log below; only then change the
   "machine draft" notice at the top of the page file and the [language statement](../language-statement.md).
   Read short labels in place, in the running interface under `/de-001/…`, not only in the file.

## Known weak spots

- Formal address (Sie). Compound nouns for project terms (for example earned value, float, baseline) were chosen without an organization's own glossary.
- Many short labels are identical to English by nature (Status, Name, Budget, Portfolio, Team).

## Widget labels (WW-1.17, a stated limit)

The words inside Lily's widgets (table sorting, paging, export and filter labels, the date picker, the Gantt chart's
controls) come from the `de-001` pack of `@lilydesignsystem/svelte-locale-translations` 0.4.0, not from this
repository's catalogues (`src/lib/lily-labels.ts`). The pack ships with `"reviewed": false`: it is a machine draft and
**not reviewed** by a speaker, and nobody in this repository has read or reviewed it either. It is used as it is, a
limit kept on purpose because the alternative is English labels. It is not in the working file above; a review of it
is done in the package, and this record then logs it. `tests/unit/review-records.test.ts` fails if the pack says it
is reviewed while this record logs no review of it.
