# Project Portfolio Management and Planview

*A commercial enterprise suite compared with an early-stage open-source project.*

**Basis of this comparison.** Planview was not installed or run for this comparison. The description is general and may be out of date, and Planview's current documentation should be checked before a decision is made. Products are not scored. Statements about this project are taken from its repository.

## About Planview

A commercial suite for enterprise portfolio and work management.

## When Planview may be the better fit

- An established enterprise vendor with support and a long production history is required
- A third-party audit or certifications are required; this project has neither
- Production use is required now, before the gaps on the [path to production](../../path-to-production/index.md) are closed

## When this project may be the better fit

- Open-source software under a choice of five licences is required
- The code and tests need to be open to inspection
- A controlled pilot on self-hosted infrastructure is the intended first step

## Migration

There is **no Planview importer**. Plans can be created through the REST API.

## Project status

This project is at an early stage, with one maintainer and no third-party audit. What production use would take, item by item with an estimate for each, is on the [path to production](../../path-to-production/index.md) page. It has no mobile app and no real-time co-editing. See [known limitations](../../topics/comparisons/index.md#known-limitations).
