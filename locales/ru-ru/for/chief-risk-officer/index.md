# Для директора по рискам

*Директор по рискам: риски, которые программа помогает увидеть, и риски её использования.*

## Риск, которым она помогает управлять

- **Риски, проблемы и запросы на изменение**, записываемые по каждому плану; реестр проблем по доступным для чтения планам; запросы на изменение с разделением обязанностей.
- **Уверенность в выполнении и исключения:** указанная уверенность хранится отдельно от рассчитанного статуса RAG, помечается при расхождении на два шага, имеет историю, в которую можно только дописывать, и 48-часовой таймер исключения, который не перезапускается при ухудшении оценки и закрывается только зафиксированным решением.
- **Честное отсутствие:** отсутствующие данные отображаются как «не оценено» или пустое значение с причиной, но никогда не как зелёный цвет или ноль.
- **Замороженный ежемесячный пакет с версиями**, чтобы то, что было сообщено директорам, можно было впоследствии показать в точности в том виде, в каком оно было выпущено.

## Риск использования (собственный реестр проекта)

| Риск | Состояние |
|---|---|
| Нет тестирования на проникновение, стороннего аудита или сертификации | Открыт: заказывает покупатель ([контрольный список обеспеченности](../../../../governance/assurance-checklist.md)) |
| Хранение соблюдается лишь для части данных | Открыт; очистку нужно поставить в расписание |
| Инструмент для запросов субъектов данных не ищет в свободном тексте, вложениях и резервных копиях | Открыт |
| Журнал аудита может быть обойдён администратором базы данных; цепочки хешей нет | Указано в [DPIA](../../../../governance/dpia.md) |
| Грифы обращения скрывают и маркируют, но не шифруют | Указано |
| Для проверки вложений нужен сканер, запускаемый тем, кто развёртывает | Открыт |
| Один сопровождающий, нет SLA | Открыт |
| Переводы — черновики | Открыт |
| Только немедицинское использование; нет обоснования клинической безопасности | Не вводите клинические сведения |

## Меры контроля, которые обеспечивает программа

Вход по умолчанию, ограничение частоты запросов, строгие заголовки безопасности, тайм-аут простоя сеанса (30 минут) и жёсткий предел длительности сеанса, исходящие адреса, ограниченные публичными `https`, вложения с проверкой подписи, неизменяемые строки аудита, аварийный доступ с аудитом. Каждая мера покрыта тестом, указанным в разделе [путь к промышленной эксплуатации](../../path-to-production/index.md).

## Решения, которые принадлежат вам

Допустимый уровень риска для пилота; окно исключений (по умолчанию 48 часов); для какого уровня грифа развёртывание прошло проверку; кто проверяет список доступа и как часто.
