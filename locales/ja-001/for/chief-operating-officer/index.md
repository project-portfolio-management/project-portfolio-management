# 最高執行責任者（COO）向け

*最高執行責任者: 日々運営しているもの、ソフトウェアがデリバリーのために行うこと、そして運用に必要なこと。*

## 業務のために行うこと

- **デリバリーの計画と管理:** 計画、タスク、依存関係、クリティカルパスの計算、計画をまたぐマイルストーン、スプリントとフェーズ、バーンダウンとフローの指標。
- **キャパシティ:** 割り当て、稼働可能状況、休暇と非稼働期間、リソースの役割、導出される作業負荷と稼働率。（ディレクターパック向けの、スキルプールと月ごとのキャパシティヒートマップは未実装です: `DP-10`。）
- **時間とコスト:** タイムシート、記録された時間、コストレート（財務に制限）、予算、導出されるコスト。
- **ガバナンスのフロー:** 課題登録簿、職務分掌付きの変更要求（要求者は承認できません）、承認、レビュー、入社・異動・退社のケース。
- **例外:** レッドまたはアンバーレッドの実行の確信度は例外を開きます。例外には、原因、必要な判断、指名されたオーナー、48 時間以内の判断期限（期間は設定可能で 1 時間から 720 時間）が必要です。違反はディレクターパックと `GET /api/exceptions` に表示されます。

## 運用に必要なもの

| 必要なもの | 詳細 |
|---|---|
| サービス | 一つの Rust サービス、PostgreSQL 18、任意の Redis（本番のキャッシュ、任意で共有セッション）、SvelteKit の UI |
| ランブック | [運用パック](../../../../operations/README.md): デプロイ、ランブック、バックアップと復元、復旧目標、アップグレードと移行 |
| 定期ジョブ | 自動でスケジュールされるものはありません。保持のパージ、例外違反の通知などは、運用担当者がスケジューラーに登録する必要があります |
| サポート | メンテナーは一人で、SLA はありません。一次サポートは自前で予算を確保してください |

## 限界を知る

- 数千タスクの計画はスケジュールに時間がかかります。完全な結果は、5,000 タスクを超えると、要求しない限り拒否されます（`?full=true` または `?only=critical`）。数値と注意点は [`BENCHMARKS.md`](../../../../BENCHMARKS.md) にあり、一台のマシンでの桁の目安であって、キャパシティではありません。
- ワークスペースの多くには画面がありますが、変更要求、課題、パック、実行の確信度には**まだ**ありません。現在は API のみです。

## あなたが決めること

各例外のオーナーを誰にするか、月次パックを誰が発行するか（リズムとリマインダーは `DP-12` で、未実装）、例外ルールがどのレビューの頻度につながるか。
