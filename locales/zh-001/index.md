# 项目组合管理

*看清组织出资的每一项工作，发现被重复做的事，并在同一个地方把它们全部管起来。*

一个免费的开源登记册，记录组织出资的每一项计划，其下是完整的项目工作区：任务、进度、资金、人员、风险和治理。当两个团队启动了同一件事时，它会告诉您，并说明判断的理由。当它给不出数字时，它会说明缺了什么，而不是去猜。

## 它如何帮助您

- **一个答案回答“我们在做什么？”** 组合、项目集、项目和产品都是同一种记录，任何计划都可以放在任何其他计划之内。只需看一份清单，而不是每个部门一张电子表格。
- **减少重复。** 可解释的匹配能找出以不同名称立项两次的同一举措，并给出证据，让您在两者都获得资金之前发现它。
- **值得信赖的数字。** 缺失的数字显示为“无预测，因为……”，绝不是猜测。无人评估的计划显示“未评估”，绝不显示绿色。
- **经得起检验的决定。** 每项变更都有审计记录，提出变更请求的人不能批准自己的请求。
- **从第一次启动就安全。** 默认启用登录，如果关闭登录，服务会拒绝在生产环境中运行。
- **始终归您所有。** 五种开源许可证任选，在您自己的服务器上运行，并可从 Jira、Asana 或 Microsoft Project 导入您的工作。

## 里面有什么

- **计划与匹配。** 可递归的登记册、可解释的重复检测和合并。
- **交付。** 看板、甘特图、日历、里程碑、关键路径和关键链。
- **资金。** 预算、资金台账、挣值，以及成本和进度风险。
- **人员。** 资源、技能池、产能热力图和关键人员。
- **战略。** 工作受理、创意、目标、目标与关键成果，以及情景。
- **治理。** 风险、问题、阶段门评审、升级和每月董事报告包。

## 适合谁

- **组合管理办公室。** 跨多个项目集的一份真实视图。
- **项目和交付经理。** 在同一处管理进度、成本和风险。
- **团队成员。** 一份清晰的个人工作清单。
- **高管和董事会。** 每个高级角色都有简短的[角色简报](for/)，说明软件能为您提供什么、不能提供什么，以及由您决定的事项。

## 坦诚的说明

这是一款年轻的软件，只有一位维护者。它没有经过第三方审计，也没有支持协议。项目自己的结论是：它**已可用于受控试点**（非临床、非机密数据），但**尚不能用于无人监督的生产环境**。[比较页面](topics/比较/index.md)说明了它的不足之处。
